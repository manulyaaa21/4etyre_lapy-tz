# Корзина

Текущий, ещё не оформленный набор выбранных товаров пользователя.

**Атрибуты:** список позиций, количество, итоговая сумма, применённый промокод.

## Связи
- принадлежит → [[Пользователь]] (1—1)
- содержит → [[Товар]] (N—M)
- преобразуется в → [[Заказ]]
- к ней применяется → [[Промокод]]
