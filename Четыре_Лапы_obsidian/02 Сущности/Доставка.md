# Доставка

Способ и статус получения заказа: курьерская доставка либо самовывоз.

**Атрибуты:** способ получения, адрес/точка выдачи, время, статус.

## Связи
- относится к → [[Заказ]] (1—1)
- выполняется через → [[Зоомагазин / ПВЗ]] либо курьерскую службу
- синхронизируется с → [[WMS / TMS]]
