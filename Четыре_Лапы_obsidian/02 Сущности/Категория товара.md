# Категория товара

Классификатор каталога: по виду животного (собаки/кошки/грызуны/птицы/рыбы/рептилии),
по назначению (корм, аксессуары, гигиена, ветпрепараты).

## Связи
- объединяет → [[Товар]] (1—N)
- редактируется через → [[Административный модуль (подсистема)]]
