# Push-уведомление

Сообщение, отправляемое пользователю о статусе заказа, акциях или напоминаниях.

## Связи
- отправляется → [[Пользователь]]
- инициируется → [[Заказ]] (смена статуса), [[Питомец]] (напоминание), [[Административный модуль (подсистема)]] (рассылка)
- доставляется через → [[Сервисы Apple]] (APNs) / [[Сервисы Google]] (FCM)

- [[Push-уведомления (подсистема)]]
