# Пользователь

Клиент сети «Четыре лапы» — владелец одного или нескольких животных.

**Атрибуты:** ID, имя, телефон, e-mail, дата регистрации, способ авторизации.

## Связи
- владеет → [[Питомец]] (1—N)
- имеет → [[Учётная запись]] (1—1)
- имеет → [[Корзина]] (1—1, текущая)
- оформляет → [[Заказ]] (1—N)
- имеет → [[Бонусный счёт]] (1—1)
- оставляет → [[Отзыв]] (1—N)
- получает → [[Push-уведомление]] (1—N)
