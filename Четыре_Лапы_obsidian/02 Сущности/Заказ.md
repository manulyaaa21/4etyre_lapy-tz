# Заказ

Оформленный и подтверждённый набор товаров с присвоенным номером и статусом.

**Атрибуты:** номер, статус (принят/собирается/передан в доставку/доставлен), дата, сумма.

## Связи
- оформлен → [[Пользователь]] (N—1)
- состоит из → [[Позиция заказа]] (1—N)
- оплачивается через → [[Платёж]] (1—1)
- доставляется через → [[Доставка]] (1—1)
- может использовать → [[Промокод]], [[Бонусный счёт]]
- порождает → [[Push-уведомление]] (изменение статуса)
- может получить → [[Отзыв]]
- передаётся в → [[1С / ERP]], [[WMS / TMS]]
